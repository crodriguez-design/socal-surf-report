# SoCal Surf Report

A personal surf dashboard for 54th St (Newport), Malibu (1st/2nd/3rd Point) and El Porto.
Ratings come from each spot's researched criteria (see [spot-guide.md](spot-guide.md)), not from swell size alone.

Live data: [Open-Meteo](https://open-meteo.com/) marine and weather (CC BY 4.0), NOAA CO-OPS tides, NOAA NDBC buoys.
Spots are configured in the `SPOTS` block near the top of `index.html`.
